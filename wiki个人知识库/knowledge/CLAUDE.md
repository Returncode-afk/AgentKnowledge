## 知识库操作提示词

### Ingest 提示词

```
请扫描 Notes/ 目录，分析每份内容并给出分类建议：

1. 读取 Notes/ 下的所有文件
2. 分析每份内容的主题和类型
3. 生成处理方案表
4. 等待用户确认后执行
```

### Query 提示词

```
在知识库中搜索相关内容：
1. 先理解用户问题的核心
2. 在 Knowledge/ 优先搜索
3. 综合多个来源给出完整答案
4. 如发现可关联的内容，建议添加链接
```

### Lint 提示词

```
执行知识库健康检查：
1. 扫描孤立页面（无引用）
2. 检查过时内容（90天未更新）
3. 找出可关联但未链接的文件
4. 生成检查报告，不自动修改
```

## 文件格式建议

Claude 在处理 Markdown 时：

### 标题层级
- 使用 `#` 表示一级标题
- 使用 `##` 表示二级标题
- 避免超过 3 级标题

### 列表格式
- 无序列表用 `-`
- 有序列表用 `1.`
- 嵌套列表缩进 2 个空格

### 代码块
- 使用 ``` 包裹
- 指定语言如 ```python
- 保持代码缩进

### 链接格式
- Wiki 链接使用 `[[概念名]]`
- 外部链接使用 `[文字](URL)`

## Claude 知识库对话示例

### 对话开始

```
用户：处理一下 Notes/ 下的新内容

Claude：
我扫描了 Notes/ 目录，发现以下文件需要处理：

| 文件 | 建议目录 | 分类理由 |
|------|----------|----------|
| 投资笔记.md | LifeOS/投资与财经 | 投资相关 |
| 产品思考.md | Knowledge/个人成长 | 方法论 |

请确认后我开始处理。
```

### 知识查询

```
用户：关于时间管理有什么好方法？

Claude：
在知识库中找到以下相关内容：

1. **深度工作法** (Knowledge/个人成长/)
   核心观点：深度工作是在无干扰状态下进行专业活动的能力

2. **番茄工作法** (Software/AI工具经验/)
   工具使用：使用计时器切割工作时间

3. **时间块管理** (LifeOS/生活管理/)
   实践方法：将一天分成多个时间块，每块专注一件事

相关页面：[[深度工作]] [[番茄工作法]]
```

## 特定功能说明

### Wiki 概念提取

Claude 可以调用 llm-wiki-compiler 来：
1. 分析文档内容
2. 提取关键概念
3. 生成概念页面
4. 建立双向链接

### 多 Agent 协作

当需要多个 Agent 协作时：
1. Manager Agent 负责任务分配
2. Worker Agent 负责具体执行
3. 通过共享的 Notes/ 进行通信
