## 四、数据模型

### 4.1 笔记本 (Notebook)

```json
{
  "id": "knowledge/个人成长/test",
  "name": "test",
  "category": "knowledge",
  "subfolder": "个人成长",
  "path": "knowledge/个人成长/test",
  "created": "2026-04-10T10:02:23.750Z",
  "updated": "2026-04-10T10:08:49.519Z"
}
```

### 4.2 笔记 (Note)

```json
{
  "id": "note-1775826187528",
  "title": "测试笔记标题",
  "modified": "2026-04-10T13:03:07.532Z",
  "notebookId": "knowledge/个人成长/test"
}
```

## 五、API 接口

| 方法 | 路径 | 描述 |
|------|------|------|
| GET | /api/categories | 获取所有分类信息 |
| GET | /api/notebooks | 获取所有笔记本 |
| POST | /api/notebooks | 创建新笔记本 |
| DELETE | /api/notebooks/:id | 删除笔记本 |
| GET | /api/notebooks/:id/notes | 获取笔记本下所有笔记 |
| POST | /api/notebooks/:id/notes | 在笔记本中创建笔记 |
| GET | /api/notes/:id | 获取笔记内容 |
| PUT | /api/notes/:id | 更新笔记内容 |
| DELETE | /api/notes/:id | 删除笔记 |
| POST | /api/compile | 编译同步Wiki |
| GET | /api/sources | 获取文档列表 |
| POST | /api/sources | 上传文档 |

## 八、安全机制

- **认证**：所有API请求需要 `Authorization: Bearer hiclaw-knowledge-api` 头
- **CORS**：允许跨域访问（`Access-Control-Allow-Origin: *`）
- **路径验证**：所有文件操作都经过路径验证，防止目录遍历攻击
